# ESP32-C6-CH375-PrintServer

Превращает обычный USB-принтер в сетевой WiFi-принтер с помощью
ESP32-C6 Super Mini в паре с внешним USB Host контроллером **CH375B** —
без Raspberry Pi и без выделенного компьютера.

У ESP32-C6 нет встроенного USB Host — поэтому принтером управляет чип
CH375B, подключённый к ESP32-C6 по быстрой **8-битной параллельной
шине** (а не по значительно более медленному UART/serial-режиму, который
CH375B тоже умеет). Плата отдаёт принтер в локальную сеть как обычный
**Raw/JetDirect (порт 9100)** и **LPR/LPD (порт 515)** сетевой принтер —
теми же протоколами, что используют настоящие сетевые принтеры и
принт-серверы. Любой компьютер в сети (Windows, macOS, Linux) может
добавить его как обычный TCP/IP-принтер, поставить родной драйвер
производителя и печатать по WiFi.

Собрано и проверено, например, на **HP LaserJet P2015**, но должно
работать с любым принтером, у которого есть стандартный двунаправленный
интерфейс USB Printer Class (07/01).

## Возможности

- **USB Host по параллельной шине через CH375B** — у ESP32-C6 нет
  встроенного USB Host-контроллера, поэтому чип CH375B управляет
  принтером через свой 8-битный параллельный интерфейс
  (RD#/WR#/A0 + D0-D7), что на порядок быстрее, чем альтернативный
  UART-режим того же чипа.
- **Два сетевых протокола печати** — Raw/AppSocket на порту 9100 и
  LPR/LPD на порту 515, оба работают одновременно. LPR обходит известную
  особенность Windows LPR-клиента, который сообщает заведомо неверную,
  завышенную длину задания — вместо того чтобы доверять этому числу,
  сервер переключается в потоковый режим.
- **Живой опрос статуса принтера по PJL** — между заданиями опрашивает
  `@PJL INFO STATUS` у PJL-совместимых (HP-подобных PCL) принтеров через
  отдельный bulk-IN USB эндпоинт и показывает "кончилась бумага" /
  "не в сети" / ошибку на дашборде и на статусном светодиоде.
- **Веб-дашборд** — небольшая тёмная панель управления прямо на плате:
  состояние принтера (с производителем/моделью, считанными из настоящих
  USB string-дескрипторов устройства, если получилось), детали
  USB-подключения, информация о WiFi, свободная память и пошаговая
  инструкция по добавлению принтера для Windows и macOS с автоматической
  подстановкой актуального IP и модели.
- **Двуязычный интерфейс (RU/EN)** — одна кнопка переключает весь
  дашборд между русским и английским, выбор сохраняется в браузере.
- **Настройка WiFi со сканированием сетей** — страница настройки сама
  сканирует ближайшие сети вместо ручного ввода SSID; ручной ввод
  по-прежнему доступен для скрытых сетей.
- **Поддержка WPA2-Enterprise (802.1X)** — помимо обычных сетей
  WPA2-PSK (или открытых), страница настройки умеет подключаться к
  WPA2-Enterprise сетям PEAP/TTLS+MSCHAPv2 (например, корпоративный WiFi
  с RADIUS-сервером) — вместо простого пароля сети запрашиваются
  Identity/Username/Password.
- **Опциональный пароль портала** — весь веб-интерфейс можно защитить
  паролем через HTTP Basic Auth (логин `admin`). Если оставить пустым,
  портал остаётся открытым.
- **SSDP/UPnP + mDNS** — плата отвечает на SSDP `M-SEARCH` и объявляет
  себя через mDNS (`ESP32-C6-PrintServer.local`), поэтому видна в списке
  устройств сети.
- **RGB-статус-светодиод** — встроенный WS2812 на плате показывает одним
  взглядом: подключение к WiFi (зелёный/красный чередуются), режим
  точки доступа для настройки (синий, мигает), принтер не на связи
  (красный, горит), простой и готовность (зелёный, горит), печать
  (зелёный, быстро мигает), удержание кнопки сброса (красный, мигает —
  приоритет надо всем), ошибка принтера / статус неизвестен (жёлтый,
  мигает).
- **Опциональный OLED-дисплей 0.91" по I2C** (SSD1306, 128×32) —
  выключен по умолчанию, включается одним `#define` в начале скетча.
- **Приоритет портала настройки** — при первом включении, или всякий
  раз когда настроенная WiFi-сеть недоступна, плата поднимает
  собственную точку доступа и остаётся полностью рабочим принтером через
  неё, без необходимости в домашней сети.

## Железо

- Плата **ESP32-C6 Super Mini**.
- Чип USB Host контроллера **CH375B**, подключённый в **параллельном
  режиме** (не serial/UART — параллельный режим примерно на порядок
  быстрее на реальных заданиях печати).

| Нога CH375B | Куда подключена |
|---|---|
| D0–D7 | ESP32-C6 GPIO18, 19, 7, 6, 3, 2, 1, 0 |
| RD# | GPIO23 |
| WR# | GPIO22 |
| A0 | GPIO21 |
| INT# | GPIO20 |
| CS# | GND (жёстко — другого устройства на шине нет) |
| TXD | GND через резистор ~1кОм — **это strapping-пин**, выбирающий параллельный/serial режим при сбросе, а не линия данных |
| RXD | не подключен (не используется в параллельном режиме) |
| RST | не подключен (это выход самого чипа, а не вход) |

> **Важно — GPIO12/GPIO13 трогать нельзя.** На ESP32-C6 эти два пина
> зашиты на уровне кристалла под встроенный USB Serial/JTAG контроллер
> (D-/D+), даже если на схеме конкретной платы это никак не отмечено.
> Если занять их под обычные GPIO (например, под параллельную шину выше)
> — COM-порт платы пропадает в тот же момент, как скетч доходит до
> `setup()`, и восстановить связь можно только принудительным входом в
> ROM-бутлоадер (держать BOOT при подаче питания) с последующей
> перезаливкой. Распиновка выше уже эти пины обходит.

- Встроенный **RGB-светодиод WS2812** (GPIO8) и **кнопка BOOT** (GPIO9,
  она же кнопка сброса WiFi-настроек — держать 10 секунд) используются
  как есть, никакой дополнительной проводки не требуют.
- **Опционально: OLED-дисплей 0.91" по I2C** (SSD1306, 128×32) — на этой
  плате под него свободны и используются GPIO4 (SDA) и GPIO5 (SCL).

## Принтеры: что точно работает, а что сложнее

Любой принтер с настоящим языком описания страницы (PCL, PostScript и
подобные) и стандартным интерфейсом USB Printer Class должен работать
хорошо — задание печати это просто заранее отрендеренный поток байт,
который передаётся как есть.

Дешёвые **"GDI"-принтеры** (например, многие Canon с проприетарным
протоколом CAPT), которые формируют растр прямо на компьютере, обычно
требуют плотного низколатентного двустороннего обмена с принтером во
время самой печати. Надёжно перенести такое через WiFi — да ещё и через
дополнительный чип USB Host поверх этого — принципиально другая и более
сложная задача, чем просто передать готовый PCL/PostScript поток; здесь
это не проверялось. Результат не гарантирован.

Пакет плат: **esp32 by Espressif Systems**.

| Параметр | Значение |

## Библиотеки

- [Adafruit NeoPixel](https://github.com/adafruit/Adafruit_NeoPixel) —
  управляет встроенным статусным светодиодом WS2812. Обязательна
  (ставится через Arduino Library Manager).
- Стандартные библиотеки ядра ESP32 Arduino (идут вместе с ядром,
  отдельно ставить не нужно): `WiFi`, `WiFiUdp`, `ESPmDNS`, `Preferences`,
  `WebServer`, `esp_wifi.h`, `esp_eap_client.h`.
- Только если включён опциональный OLED (раскомментирован
  `ENABLE_OLED_DISPLAY` в начале скетча): `Adafruit_SSD1306` и
  `Adafruit_GFX` (обе через Library Manager). Если дисплей выключен —
  ни одна из них не нужна.

## Быстрый старт

1. Распаяйте CH375B к ESP32-C6 по таблице выше, включая резистор
   strapping на TXD и CS# на землю.
2. Выставьте настройки платы выше в Arduino IDE и залейте скетч.
3. При первом включении плата поднимает точку доступа
   `CH375-PrintServer-Setup` (пароль `12345678`). **Печатать можно сразу
   через эту точку доступа** — подключите к ней компьютер и добавьте
   сетевой принтер по адресу `192.168.4.1` (Raw порт 9100 или LPR порт
   515), домашняя сеть для этого не нужна. Так же плата ведёт себя
   всегда, когда не может достучаться до настроенной сети — то есть
   всегда остаётся рабочим принтером, а не просто "молчит".
4. Откройте `http://192.168.4.1/wifi`, выберите свою сеть из
   просканированного списка (или введите вручную / включите
   WPA2-Enterprise) и сохраните. Плата перезагрузится и подключится к
   вашей сети. На этой же странице можно сразу задать и пароль
   портала — по желанию.
5. После подключения к домашней сети откройте IP-адрес платы в браузере
   для живого дашборда, либо зайдите на
   `http://ESP32-C6-PrintServer.local`, если ваша ОС поддерживает mDNS.
6. На компьютере добавьте новый сетевой принтер по адресу платы — либо
   через **Raw/AppSocket на порту 9100**, либо через **LPR на порту
   515** — и установите обычный драйвер принтера. Пошаговая инструкция
   для Windows и macOS показана прямо на дашборде, с автоматической
   подстановкой реальной модели принтера и текущего IP платы.
